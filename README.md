# Banking Management System

## Description
A menu-driven Banking Management System developed using Java to manage multiple bank accounts and perform basic banking operations.

## Features
- Create multiple bank accounts
- Search accounts using account numbers
- Deposit and withdraw money
- Check account balance
- Display account details
- Perform multiple operations on the same account
- Switch between different accounts

## Concepts Used
- Classes and Objects
- Constructors
- Arrays of Objects
- Methods
- For and Do-While Loops
- If-Else Statements
- Switch Case
- Scanner Class

## How to Run
```bash
javac BankAccount.java
java BankAccount
